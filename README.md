#IDEONIX

Ideonix is a modern idea-sharing platform where users can post innovative ideas, explore trending concepts, and collaborate with others. It aims to create a space where creativity turns into real-world projects.

✨ Key Features:<br>
• Share and explore ideas<br>
• Collaboration opportunities<br>
• User Profile Management<br>
• Login & Signup systems<br>
• Clean and modern UI<br>
• Dark mode support<br>
• Interactive background<br>

🛠️ Built with: HTML, CSS, JavaScript
